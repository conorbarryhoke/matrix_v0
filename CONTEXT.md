I am building a tool that will help create custom monsters and adapt existing ones.

My plan for this is to have a model that tells me the value of each independent feature.

My feeling is that DnD monsters have too many hitpoints and not enough features / damage. So they are often uninteresting to fight, either because all do is hit and soak up damage. I would like to create a consistent framework for adding features to a monster without making it too strong.
